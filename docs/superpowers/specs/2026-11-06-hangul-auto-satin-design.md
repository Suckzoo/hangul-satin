# 한글 폰트 자동 satin 경로 설계

## 의도

TTF/OTF 한글 폰트 파일을 받아서 InkStitch lettering 폰트 폴더를 자동으로 만든다. 경로 품질은 자수 전문가가 받아들일 수 있어야 한다. 자동 결과가 나쁜 글자는 조용히 내보내지 않고 표시한다.

## 전문가 요구 사항 (2026-11-06)

1. `ㅏ`, `ㅒ`처럼 기둥에 곁획이 교차하면 기둥은 균일한 일자로 간다.
2. 곁획은 끝까지 덮는다. (Black `가`의 곁획 빈 곳이 불량 사례다.)
3. `꺪`의 `ㄲ` 같은 곳에 의도하지 않은 빈 공간이 없어야 한다.
4. `ㅒ`는 일자 기둥 2개와 교차하는 직선 2개로 나눈다. Regular, Bold, Black 모두 같다.
5. `ㅇ`은 최대한 방사형으로 처리한다. 안쪽이 과하게 빽빽하면 현행을 유지해도 된다.

## 목표

- 위 5건을 CookieRun Regular, Bold, Black의 `가`, `감`, `꺪`, `앙`에서 만족한다.
- 임의의 폰트에서 실패 글자를 자동으로 표시한다.
- 결과 폴더는 수정 없이 InkStitch `Font`로 읽힌다.

## 비목표

- 모든 폰트에서 100% 자동 품질. 손글씨체와 장식체의 실패는 허용하고 표시한다.
- AI 또는 MCP 연동. 지금 범위가 아니다.
- Inkscape 확장 UI와 GUI. CLI 다음의 별도 계획으로 다룬다.
- PE-Design 알고리즘 복제.

## 실패로 보는 결과 (anti-goal)

- 수치 기준은 통과하지만 보기 싫은 경로를 "통과"로 표시한다. 전문가 검토를 수치로 대체하지 않는다.
- 저작권이 있는 폰트 파일 또는 그 파생물을 저장소에 커밋한다.

## 알고리즘 (prototype으로 확인함)

1. 글자 외곽선을 polygon으로 만들고 연결 요소별로 처리한다.
2. **기둥 찾기:** 한쪽 변이 끊겼다가 같은 직선으로 이어지는 띠를 찾는다. 끊긴 길이는 기둥 폭의 40% 이상이고, 어느 한쪽에 기둥 길이 60% 이상의 직선 변이 있어야 한다.
3. **기둥 satin:** 영역을 기둥 축에 수직으로 잘라서 rail과 rung을 만든다. 모든 stitch가 평행하다.
4. **남은 영역:** 외곽선에서 기둥을 뺀 조각을 기둥 축의 수직 방향으로 잘라서 만들고, 기둥 밑으로 조금 넣는다. 기둥보다 먼저 수놓는다.
5. **기둥 없는 요소:** Voronoi centerline과 접점 rung을 쓴다. 고리는 방사형, 뾰족한 안쪽 모서리는 miter로 나눈다. 곧은 조각은 3번 방식으로 다시 만든다.
6. **빈틈:** 덮이지 않은 조각을 이웃 획에 합치거나 이웃 획 밑의 patch로 만든다.

prototype: `docs/superpowers/prototypes/hangul-satin/`. 비교 페이지: https://claude.ai/artifact/5QEkY6KDpi8ekfvUG91BD7

## 합격 기준

제가 prototype 수치를 근거로 정한 임시 값이다. 전문가 검토와 시험 자수로 조정한다.

| 지표 | 기준 | 비고 |
|---|---|---|
| 최대 빈틈 지름 | 0.5mm 이하 | top stitch를 0.4mm 실로 계산, prototype 최대 0.37mm |
| 기둥 stitch 기울기(p95) | atan(간격 ÷ 폭) + 1.5° 이하 | satin 지그재그 기울기는 피할 수 없음 |
| 최장 stitch | 7mm 이하 또는 분할 | Black 30mm에서 초과 |

## 빌더에게 맡기는 부분

- 내부 자료 구조와 함수 분할. 계획 문서의 interface는 지켜야 한다.
- CLI 옵션의 세부 이름.

## 전문가 확인 후 정할 부분

- `ㅁ`, `ㄱ` 모서리: 현재 값은 miter다.
- `ㅇ` 안쪽 과밀 기준값: 현재 값은 "기준 없음, 항상 방사형"이다.
- `ㄲ` 접합부에서 위로 올릴 획.
